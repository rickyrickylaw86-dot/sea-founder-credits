How entries are checked

Every entry links to the provider's own page (or the best public source we could find) and shows the date it was last checked.

  • Values are copied as stated, in the provider's currency. If a page doesn't state an amount we write "not stated". We never estimate.
  • Verified means we read the value on the live official page (or an official/government source) on the date shown. Unverified entries are real programs whose current terms we haven't confirmed yet. Check the source before applying.
  • No VC needed means you can apply without an investor or accelerator referral code. Some still need a registered company.
  • Weekly refresh: each week we re-open every source link, update values and deadlines, mark closed programs, and add new ones. The newsletter lists what changed.
  • Global programs are open worldwide, including Southeast Asia, so they show under every country filter.

Spotted an error? Corrections are welcome: email seafoundercredits@agentmail.to.
